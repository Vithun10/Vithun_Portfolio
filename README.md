# Vithun TR — Business Operations & Analytics Portfolio

A professional portfolio showcasing my work across **Business Operations, Process Improvement, Business Analytics, and Data-Driven Decision Support**.

I focus on connecting business challenges with analytical evidence to identify operational gaps, improve processes, and support better business decisions.

## Featured Projects

### 1. FLOW — Operational Process & Pipeline Analysis
A business operations case study focused on application pipeline performance, process bottlenecks, SLA adherence, rework, and capacity planning.

### 2. TRIAGE — Risk Intelligence & Onboarding Analysis
A risk analytics case study exploring customer onboarding performance, risk segmentation, turnaround time, and verification workflows.

*Both projects use synthetic datasets and are presented for analytical and portfolio demonstration purposes.*

## Run Locally

```bash

# Navigate into the project
cd Vithun_Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```
